# dokploy_gitea (Resource)

Manages a Dokploy Gitea provider integration. Allows connecting to self-hosted Gitea instances for source code access.

## Example Usage

```terraform
# Self-hosted Gitea provider
resource "dokploy_gitea" "main" {
  name      = "company-gitea"
  gitea_url = "https://gitea.example.com"

  # OAuth configuration
  client_id     = var.gitea_client_id
  client_secret = var.gitea_client_secret
  redirect_uri  = "https://dokploy.example.com/oauth/callback"
}

# Gitea with organization restriction
resource "dokploy_gitea" "org" {
  name      = "gitea-org"
  gitea_url = "https://gitea.example.com"

  gitea_username    = "deploy-user"
  organization_name = "my-org"

  access_token = var.gitea_access_token
}
```

## Schema

### Required

- `gitea_url` (String) The Gitea instance URL (e.g., https://gitea.example.com).
- `name` (String) The name of the Gitea provider.

### Optional

- `access_token` (String, Sensitive) The OAuth access token.
- `client_id` (String) The Gitea OAuth application client ID.
- `client_secret` (String, Sensitive) The Gitea OAuth application client secret.
- `expires_at` (Number) The token expiration timestamp.
- `gitea_username` (String) The Gitea username.
- `organization_name` (String) The Gitea organization name to restrict repository access.
- `redirect_uri` (String) The OAuth redirect URI.
- `refresh_token` (String, Sensitive) The OAuth refresh token.
- `scopes` (String) The OAuth scopes requested.

### Read-Only

- `git_provider_id` (String) The git provider identifier used for deletion.
- `id` (String) The unique identifier of the Gitea provider (giteaId).

## Import

Gitea providers can be imported using their Gitea ID:

```shell
terraform import dokploy_gitea.example abc123-gitea-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_gitea.example
  id = "abc123-gitea-id"
}
```

~> **Note:** Sensitive fields like `client_secret`, `access_token`, and `refresh_token` will not be readable after import. You will need to set these values in your configuration after import.
