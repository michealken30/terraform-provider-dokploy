# dokploy_destination (Resource)

Manages a Dokploy backup destination. Destinations are S3-compatible storage locations for database backups.

## Example Usage

```terraform
# Configure S3 backup destination

resource "dokploy_destination" "backups" {
  name              = "s3-backups"
  access_key        = var.aws_access_key
  secret_access_key = var.aws_secret_key
  bucket            = "my-dokploy-backups"
  region            = "us-east-1"
  endpoint          = "https://s3.amazonaws.com"
  organization_id   = var.organization_id
}

variable "aws_access_key" {
  description = "AWS access key ID"
  type        = string
}

variable "aws_secret_key" {
  description = "AWS secret access key"
  type        = string
  sensitive   = true
}

variable "organization_id" {
  description = "Dokploy organization ID"
  type        = string
}

output "destination_id" {
  value = dokploy_destination.backups.id
}
```

## Import

Destinations can be imported using their ID:

```shell
terraform import dokploy_destination.example nop012-destination-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_destination.example
  id = "nop012-destination-id"
}
```

### Finding Destination IDs

Use the `dokploy_destinations` data source to discover destination IDs:

```hcl
data "dokploy_destinations" "all" {}

output "destination_ids" {
  value = { for d in data.dokploy_destinations.all.destinations : d.name => d.id }
}
```

~> **Note:** Sensitive values like `access_key` and `secret_access_key` will not be populated during import. You will need to set these values in your configuration after import.
