# dokploy_mount (Resource)

Manages a Dokploy mount for a service. Supports bind mounts, Docker volumes, and file mounts.

## Example Usage

```terraform
# Docker volume mount
resource "dokploy_mount" "data" {
  type         = "volume"
  volume_name  = "app-data"
  mount_path   = "/app/data"
  service_type = "application"
  service_id   = dokploy_application.web.id
}

# Bind mount from host
resource "dokploy_mount" "config" {
  type         = "bind"
  host_path    = "/etc/app/config"
  mount_path   = "/app/config"
  service_type = "application"
  service_id   = dokploy_application.web.id
}

# File mount with inline content
resource "dokploy_mount" "env_file" {
  type         = "file"
  content      = <<-EOT
    DATABASE_URL=postgresql://user:pass@localhost/db
    SECRET_KEY=abc123
  EOT
  mount_path   = "/app/.env"
  service_type = "application"
  service_id   = dokploy_application.web.id
}

# Mount for PostgreSQL database
resource "dokploy_mount" "postgres_data" {
  type         = "volume"
  volume_name  = "postgres-data"
  mount_path   = "/var/lib/postgresql/data"
  service_type = "postgres"
  service_id   = dokploy_postgres.db.id
}
```

## Schema

### Required

- `mount_path` (String) The path inside the container where the mount will be available.
- `service_id` (String) The ID of the service (application, database, or compose) this mount belongs to.
- `type` (String) The type of mount. Valid values: 'bind', 'volume', 'file'.

### Optional

- `content` (String) The file content for file mounts. Required when type is 'file'.
- `file_path` (String) The path where the file should be created for file mounts.
- `host_path` (String) The path on the host for bind mounts. Required when type is 'bind'.
- `service_type` (String) The type of service this mount belongs to. Valid values: 'application', 'postgres', 'mysql', 'mariadb', 'mongo', 'redis', 'compose'. Defaults to 'application'.
- `volume_name` (String) The name of the Docker volume. Required when type is 'volume'.

### Read-Only

- `id` (String) The unique identifier of the mount.
