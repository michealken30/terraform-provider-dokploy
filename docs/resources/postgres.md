# dokploy_postgres (Resource)

Manages a Dokploy PostgreSQL database service within an environment.

## Example Usage

```terraform
# Create a PostgreSQL database

resource "dokploy_project" "example" {
  name = "my-project"
}

resource "dokploy_environment" "prod" {
  project_id = dokploy_project.example.id
  name       = "prod"
}

resource "dokploy_postgres" "main" {
  environment_id = dokploy_environment.prod.id
  name           = "main-db"
  description    = "Primary PostgreSQL database"
  database_name  = "appdb"
  database_user  = "appuser"
  docker_image   = "postgres:16-alpine"
}

output "postgres_id" {
  value = dokploy_postgres.main.id
}

output "postgres_password" {
  value     = dokploy_postgres.main.database_password
  sensitive = true
}
```

## Schema

### Required

- `environment_id` (String) The ID of the environment this database belongs to.
- `name` (String) The name of the postgres database.

### Optional

- `database_name` (String) The name of the database to create.
- `database_password` (String, Sensitive) The database password.
- `database_user` (String) The database user.
- `description` (String) The description of the postgres database.
- `docker_image` (String) The Docker image to use (e.g., postgres:16).
- `server_id` (String) The ID of the server to deploy to (optional, uses default if not specified).

### Read-Only

- `app_name` (String) The internal app name (used for container naming). Computed by Dokploy.
- `id` (String) The unique identifier of the postgres database.

## Import

PostgreSQL databases can be imported using their ID:

```shell
terraform import dokploy_postgres.example mno345-postgres-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_postgres.example
  id = "mno345-postgres-id"
}
```

### Finding PostgreSQL IDs

Use the `dokploy_environments` data source to discover PostgreSQL IDs within environments:

```hcl
data "dokploy_environments" "all" {
  project_id = dokploy_project.example.id
}

output "postgres_ids" {
  value = flatten([
    for env in data.dokploy_environments.all.environments : [
      for pg in env.postgres : {
        environment = env.name
        name        = pg.name
        id          = pg.id
      }
    ]
  ])
}
```

~> **Note:** Sensitive values like `database_password` will not be populated during import. You will need to set these values in your configuration after import.
