# dokploy_mongo (Resource)

Manages a Dokploy MongoDB database service within an environment.

## Example Usage

```terraform
# Create a MongoDB database

resource "dokploy_project" "example" {
  name = "my-project"
}

resource "dokploy_environment" "prod" {
  project_id = dokploy_project.example.id
  name       = "prod"
}

resource "dokploy_mongo" "main" {
  environment_id = dokploy_environment.prod.id
  name           = "mongodb"
  description    = "MongoDB document store"
  docker_image   = "mongo:7"
}

output "mongo_id" {
  value = dokploy_mongo.main.id
}
```

## Schema

### Required

- `environment_id` (String) The ID of the environment this database belongs to.
- `name` (String) The name of the mongo database.

### Optional

- `database_password` (String, Sensitive) The database password.
- `database_user` (String) The database user.
- `description` (String) The description of the mongo database.
- `docker_image` (String) The Docker image to use (e.g., mongo:7).
- `server_id` (String) The ID of the server to deploy to (optional, uses default if not specified).

### Read-Only

- `app_name` (String) The internal app name (used for container naming). Computed by Dokploy.
- `id` (String) The unique identifier of the mongo database.

## Import

MongoDB databases can be imported using their ID:

```shell
terraform import dokploy_mongo.example vwx234-mongo-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_mongo.example
  id = "vwx234-mongo-id"
}
```

### Finding MongoDB IDs

Use the `dokploy_environments` data source to discover MongoDB IDs within environments:

```hcl
data "dokploy_environments" "all" {
  project_id = dokploy_project.example.id
}

output "mongo_ids" {
  value = flatten([
    for env in data.dokploy_environments.all.environments : [
      for m in env.mongo : {
        environment = env.name
        name        = m.name
        id          = m.id
      }
    ]
  ])
}
```

~> **Note:** Sensitive values like `database_password` will not be populated during import. You will need to set these values in your configuration after import.
