# dokploy_environment (Resource)

Manages a Dokploy environment within a project. Environments contain applications, databases, and compose services.

## Example Usage

```terraform
# Create an environment within a project

resource "dokploy_project" "example" {
  name = "my-project"
}

resource "dokploy_environment" "staging" {
  project_id  = dokploy_project.example.id
  name        = "staging"
  description = "Staging environment"
}

output "environment_id" {
  value = dokploy_environment.staging.id
}
```

- `id` (String) The unique identifier of the environment.

## Import

Environments can be imported using their ID:

```shell
terraform import dokploy_environment.example def456-environment-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_environment.example
  id = "def456-environment-id"
}
```

### Finding Environment IDs

Use the `dokploy_environments` data source to discover environment IDs:

```hcl
data "dokploy_environments" "all" {
  project_id = dokploy_project.example.id
}

output "environment_ids" {
  value = { for e in data.dokploy_environments.all.environments : e.name => e.id }
}
```
