# dokploy_notification (Resource)

Manages a Dokploy notification configuration. Supports Slack, Discord, Telegram, and Email notification providers.

## Example Usage

```terraform
# Slack notification
resource "dokploy_notification" "slack" {
  name              = "deploy-alerts"
  notification_type = "slack"

  # Event triggers
  app_deploy      = true
  app_build_error = true
  database_backup = true

  # Slack-specific configuration
  slack_webhook_url = var.slack_webhook_url
  slack_channel     = "#deployments"
}

# Discord notification
resource "dokploy_notification" "discord" {
  name              = "build-alerts"
  notification_type = "discord"

  # Event triggers
  app_build_error = true
  docker_cleanup  = true

  # Discord-specific configuration
  discord_webhook_url = var.discord_webhook_url
  discord_decoration  = true
}

# Telegram notification
resource "dokploy_notification" "telegram" {
  name              = "server-alerts"
  notification_type = "telegram"

  # Event triggers
  server_threshold = true
  dokploy_restart  = true

  # Telegram-specific configuration
  telegram_bot_token        = var.telegram_bot_token
  telegram_chat_id          = var.telegram_chat_id
  telegram_message_thread_id = ""
}

# Email notification
resource "dokploy_notification" "email" {
  name              = "backup-alerts"
  notification_type = "email"

  # Event triggers
  database_backup = true
  volume_backup   = true

  # Email-specific configuration
  email_smtp_server  = "smtp.example.com"
  email_smtp_port    = 587
  email_username     = "alerts@example.com"
  email_password     = var.smtp_password
  email_from_address = "alerts@example.com"
  email_to_addresses = ["admin@example.com", "ops@example.com"]
}
```

## Schema

### Required

- `name` (String) The name of the notification.
- `notification_type` (String) The type of notification. Valid values: 'slack', 'discord', 'telegram', 'email'.

### Optional

- `app_build_error` (Boolean) Notify on application build errors.
- `app_deploy` (Boolean) Notify on application deployment.
- `database_backup` (Boolean) Notify on database backup completion.
- `discord_decoration` (Boolean) Enable Discord message decoration. Required when notification_type is 'discord'.
- `discord_webhook_url` (String, Sensitive) Discord webhook URL. Required when notification_type is 'discord'.
- `docker_cleanup` (Boolean) Notify on Docker cleanup.
- `dokploy_restart` (Boolean) Notify on Dokploy restart.
- `email_from_address` (String) From email address. Required when notification_type is 'email'.
- `email_password` (String, Sensitive) SMTP password. Required when notification_type is 'email'.
- `email_smtp_port` (Number) SMTP server port. Required when notification_type is 'email'.
- `email_smtp_server` (String) SMTP server hostname. Required when notification_type is 'email'.
- `email_to_addresses` (List of String) List of recipient email addresses. Required when notification_type is 'email'.
- `email_username` (String) SMTP username. Required when notification_type is 'email'.
- `server_threshold` (Boolean) Notify when server thresholds are exceeded.
- `slack_channel` (String) Slack channel name. Required when notification_type is 'slack'.
- `slack_webhook_url` (String, Sensitive) Slack webhook URL. Required when notification_type is 'slack'.
- `telegram_bot_token` (String, Sensitive) Telegram bot token. Required when notification_type is 'telegram'.
- `telegram_chat_id` (String) Telegram chat ID. Required when notification_type is 'telegram'.
- `telegram_message_thread_id` (String) Telegram message thread ID for topics.
- `volume_backup` (Boolean) Notify on volume backup completion.

### Read-Only

- `id` (String) The unique identifier of the notification.

## Import

Notifications can be imported using their ID:

```shell
terraform import dokploy_notification.example abc123-notification-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_notification.example
  id = "abc123-notification-id"
}
```

~> **Note:** Sensitive fields like webhook URLs, bot tokens, and passwords will not be readable after import. You will need to set these values in your configuration after import.
