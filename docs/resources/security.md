# dokploy_security (Resource)

Manages a Dokploy security entry for an application. Security entries provide HTTP basic authentication protection.

## Example Usage

```terraform
# Basic authentication for an application
resource "dokploy_security" "admin" {
  username       = "admin"
  password       = var.admin_password
  application_id = dokploy_application.admin_panel.id
}

# Multiple users for the same application
resource "dokploy_security" "readonly" {
  username       = "viewer"
  password       = var.viewer_password
  application_id = dokploy_application.admin_panel.id
}
```

## Schema

### Required

- `application_id` (String) The ID of the application this security entry belongs to.
- `password` (String, Sensitive) The password for basic authentication.
- `username` (String) The username for basic authentication.

### Read-Only

- `id` (String) The unique identifier of the security entry.

## Import

Security entries can be imported using their ID:

```shell
terraform import dokploy_security.example abc123-security-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_security.example
  id = "abc123-security-id"
}
```

~> **Note:** The `password` value will not be accessible after import. You will need to set this value in your configuration after import.
