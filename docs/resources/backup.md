# dokploy_backup (Resource)

Manages a Dokploy backup configuration for a database or compose service. Backups are scheduled using cron expressions and stored in S3-compatible destinations.

## Example Usage

```terraform
# Daily PostgreSQL backup
resource "dokploy_backup" "postgres_daily" {
  schedule          = "0 0 * * *" # Daily at midnight
  enabled           = true
  prefix            = "postgres-daily"
  destination_id    = dokploy_destination.s3.id
  database          = "myapp"
  database_type     = "postgres"
  backup_type       = "database"
  postgres_id       = dokploy_postgres.db.id
  keep_latest_count = 7
}

# Weekly MySQL backup with retention
resource "dokploy_backup" "mysql_weekly" {
  schedule          = "0 0 * * 0" # Weekly on Sunday
  enabled           = true
  prefix            = "mysql-weekly"
  destination_id    = dokploy_destination.s3.id
  database          = "production"
  database_type     = "mysql"
  backup_type       = "database"
  mysql_id          = dokploy_mysql.db.id
  keep_latest_count = 4
}

# MongoDB backup
resource "dokploy_backup" "mongo" {
  schedule       = "0 */6 * * *" # Every 6 hours
  enabled        = true
  prefix         = "mongo"
  destination_id = dokploy_destination.s3.id
  database       = "documents"
  database_type  = "mongo"
  backup_type    = "database"
  mongo_id       = dokploy_mongo.db.id
}
```

## Schema

### Required

- `database` (String) The database name to backup.
- `database_type` (String) The type of database. Valid values: 'postgres', 'mysql', 'mariadb', 'mongo', 'web-server'.
- `destination_id` (String) The ID of the backup destination (S3 bucket, etc.).
- `prefix` (String) Prefix for backup file names.
- `schedule` (String) Cron expression for the backup schedule (e.g., '0 0 * * *' for daily at midnight).

### Optional

- `backup_type` (String) The type of backup. Valid values: 'database', 'compose'. Defaults to 'database'.
- `compose_id` (String) The ID of the compose service to backup. Required when backup_type is 'compose'.
- `enabled` (Boolean) Whether the backup is enabled. Defaults to true.
- `keep_latest_count` (Number) Number of recent backups to keep. Older backups will be deleted.
- `mariadb_id` (String) The ID of the MariaDB service to backup. Required when database_type is 'mariadb'.
- `mongo_id` (String) The ID of the MongoDB service to backup. Required when database_type is 'mongo'.
- `mysql_id` (String) The ID of the MySQL service to backup. Required when database_type is 'mysql'.
- `postgres_id` (String) The ID of the Postgres service to backup. Required when database_type is 'postgres'.
- `service_name` (String) The service name within a compose stack. Required when compose_id is set.

### Read-Only

- `id` (String) The unique identifier of the backup.
