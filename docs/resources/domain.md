# dokploy_domain (Resource)

Manages a Dokploy domain for an application or compose service. Domains expose applications via custom hostnames with optional SSL certificates.

## Example Usage

```terraform
# Basic domain with Let's Encrypt SSL
resource "dokploy_domain" "example" {
  host             = "app.example.com"
  application_id   = dokploy_application.web.id
  https            = true
  certificate_type = "letsencrypt"
}

# Domain with path prefix
resource "dokploy_domain" "api" {
  host             = "api.example.com"
  path             = "/v1"
  application_id   = dokploy_application.api.id
  https            = true
  certificate_type = "letsencrypt"
  strip_path       = true
}

# Domain for compose service
resource "dokploy_domain" "compose_web" {
  host             = "web.example.com"
  compose_id       = dokploy_compose.stack.id
  service_name     = "nginx"
  https            = true
  certificate_type = "letsencrypt"
}
```

## Schema

### Required

- `host` (String) The domain hostname (e.g., 'example.com' or 'app.example.com').

### Optional

- `application_id` (String) The ID of the application this domain belongs to. Either application_id or compose_id must be set.
- `certificate_type` (String) The type of SSL certificate to use. Valid values: 'letsencrypt', 'none', 'custom'.
- `compose_id` (String) The ID of the compose service this domain belongs to. Either application_id or compose_id must be set.
- `custom_cert_resolver` (String) Custom certificate resolver name when certificate_type is 'custom'.
- `domain_type` (String) The type of domain. Valid values: 'compose', 'application', 'preview'. Auto-detected if not set.
- `https` (Boolean) Whether to enable HTTPS for this domain.
- `internal_path` (String) Internal path for routing within the application.
- `path` (String) The URL path prefix for the domain (e.g., '/api'). Defaults to '/'.
- `port` (Number) The target port to route traffic to. Defaults to the application's exposed port.
- `service_name` (String) The service name within a compose stack. Required when compose_id is set.
- `strip_path` (Boolean) Whether to strip the path prefix before forwarding to the application.

### Read-Only

- `id` (String) The unique identifier of the domain.
- `unique_config_key` (Number) Unique configuration key assigned by Dokploy.

## Import

Domains can be imported using their ID:

```shell
terraform import dokploy_domain.example abc123-domain-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_domain.example
  id = "abc123-domain-id"
}
```
