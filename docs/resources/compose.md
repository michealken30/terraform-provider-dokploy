# dokploy_compose (Resource)

Manages a Dokploy Docker Compose service. Compose services allow deploying multi-container applications defined in docker-compose.yml files.

## Example Usage

```terraform
# Create a Docker Compose service

resource "dokploy_project" "example" {
  name = "my-project"
}

resource "dokploy_environment" "prod" {
  project_id = dokploy_project.example.id
  name       = "prod"
}

resource "dokploy_compose" "monitoring" {
  environment_id = dokploy_environment.prod.id
  name           = "monitoring"
  description    = "Prometheus and Grafana stack"
  compose_type   = "docker-compose"
  compose_file   = <<-EOT
    version: '3.8'
    services:
      prometheus:
        image: prom/prometheus:latest
        ports:
          - "9090:9090"
      grafana:
        image: grafana/grafana:latest
        ports:
          - "3000:3000"
  EOT
}

output "compose_id" {
  value = dokploy_compose.monitoring.id
}
```

## Schema

### Required

- `environment_id` (String) The ID of the environment this compose service belongs to.
- `name` (String) The name of the compose service.

### Optional

- `compose_file` (String) The docker-compose.yml content.
- `compose_path` (String) The path to the compose file (default: ./docker-compose.yml).
- `compose_type` (String) The compose type (docker-compose or stack).
- `description` (String) The description of the compose service.
- `server_id` (String) The ID of the server to deploy to (optional, uses default if not specified).

### Read-Only

- `app_name` (String) The internal app name (used for container naming). Computed by Dokploy.
- `id` (String) The unique identifier of the compose service.

## Import

Compose services can be imported using their ID:

```shell
terraform import dokploy_compose.example jkl012-compose-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_compose.example
  id = "jkl012-compose-id"
}
```

### Finding Compose IDs

Use the `dokploy_environments` data source to discover compose IDs within environments:

```hcl
data "dokploy_environments" "all" {
  project_id = dokploy_project.example.id
}

output "compose_ids" {
  value = flatten([
    for env in data.dokploy_environments.all.environments : [
      for c in env.compose : {
        environment = env.name
        name        = c.name
        id          = c.id
      }
    ]
  ])
}
```
