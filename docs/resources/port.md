# dokploy_port (Resource)

Manages a Dokploy port mapping for an application. Ports expose container ports to the host.

## Example Usage

```terraform
# Expose a TCP port
resource "dokploy_port" "http" {
  published_port = 8080
  target_port    = 80
  protocol       = "tcp"
  application_id = dokploy_application.web.id
}

# Expose a UDP port
resource "dokploy_port" "dns" {
  published_port = 5353
  target_port    = 53
  protocol       = "udp"
  application_id = dokploy_application.dns.id
}

# Host mode port (bypasses ingress)
resource "dokploy_port" "metrics" {
  published_port = 9090
  target_port    = 9090
  protocol       = "tcp"
  publish_mode   = "host"
  application_id = dokploy_application.metrics.id
}
```

## Schema

### Required

- `application_id` (String) The ID of the application this port mapping belongs to.
- `published_port` (Number) The external port to expose on the host.
- `target_port` (Number) The internal container port to map to.

### Optional

- `protocol` (String) The network protocol. Valid values: 'tcp', 'udp'. Defaults to 'tcp'.
- `publish_mode` (String) The publish mode for swarm. Valid values: 'ingress', 'host'. Defaults to 'ingress'.

### Read-Only

- `id` (String) The unique identifier of the port mapping.
