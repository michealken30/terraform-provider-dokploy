# dokploy_schedule (Resource)

Manages a Dokploy scheduled task (cron job) for an application, compose service, or server. Schedules execute commands at specified intervals.

## Example Usage

```terraform
# Application cron job
resource "dokploy_schedule" "cleanup" {
  name            = "daily-cleanup"
  cron_expression = "0 0 * * *"
  command         = "php artisan cleanup:run"
  shell_type      = "bash"
  schedule_type   = "application"
  application_id  = dokploy_application.web.id
  enabled         = true
  timezone        = "America/New_York"
}

# Compose service cron job
resource "dokploy_schedule" "db_optimize" {
  name            = "weekly-optimize"
  cron_expression = "0 3 * * 0"
  command         = "mysqlcheck --optimize --all-databases"
  shell_type      = "sh"
  schedule_type   = "compose"
  compose_id      = dokploy_compose.stack.id
  service_name    = "mysql"
  enabled         = true
}

# Server-level cron job
resource "dokploy_schedule" "docker_prune" {
  name            = "docker-prune"
  cron_expression = "0 4 * * *"
  command         = "docker system prune -af --volumes"
  shell_type      = "bash"
  schedule_type   = "server"
  server_id       = dokploy_server.worker.id
  enabled         = true
}

# Health check script
resource "dokploy_schedule" "health_check" {
  name            = "health-check"
  cron_expression = "*/5 * * * *"
  command         = "curl -sf http://localhost:3000/health || exit 1"
  shell_type      = "bash"
  schedule_type   = "application"
  application_id  = dokploy_application.api.id
  enabled         = true
}
```

## Schema

### Required

- `command` (String) The command to execute.
- `cron_expression` (String) Cron expression for the schedule (e.g., '*/5 * * * *' for every 5 minutes).
- `name` (String) The name of the scheduled task.

### Optional

- `app_name` (String) The application name for the schedule. Used for container identification.
- `application_id` (String) The ID of the application this schedule belongs to. Required when schedule_type is 'application'.
- `compose_id` (String) The ID of the compose service this schedule belongs to. Required when schedule_type is 'compose'.
- `enabled` (Boolean) Whether the schedule is enabled. Defaults to true.
- `schedule_type` (String) The type of schedule. Valid values: 'application', 'compose', 'server', 'dokploy-server'. Defaults to 'application'.
- `script` (String) An optional script to execute instead of a command.
- `server_id` (String) The ID of the server this schedule belongs to. Required when schedule_type is 'server'.
- `service_name` (String) The service name within a compose stack. Required when schedule_type is 'compose'.
- `shell_type` (String) The shell to use for executing the command. Valid values: 'bash', 'sh'. Defaults to 'bash'.
- `timezone` (String) The timezone for the schedule (e.g., 'America/New_York').

### Read-Only

- `id` (String) The unique identifier of the schedule.
