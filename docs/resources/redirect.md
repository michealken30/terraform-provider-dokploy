# dokploy_redirect (Resource)

Manages a Dokploy redirect rule for an application. Redirects use regex patterns to match and rewrite URLs.

## Example Usage

```terraform
# Redirect www to non-www
resource "dokploy_redirect" "www_to_apex" {
  regex          = "^https://www\\.example\\.com/(.*)"
  replacement    = "https://example.com/$1"
  permanent      = true
  application_id = dokploy_application.web.id
}

# Redirect old paths to new paths
resource "dokploy_redirect" "legacy_api" {
  regex          = "^/api/v1/(.*)"
  replacement    = "/api/v2/$1"
  permanent      = false
  application_id = dokploy_application.api.id
}

# Redirect all HTTP to HTTPS
resource "dokploy_redirect" "force_https" {
  regex          = "^http://(.*)$"
  replacement    = "https://$1"
  permanent      = true
  application_id = dokploy_application.web.id
}
```

## Schema

### Required

- `application_id` (String) The ID of the application this redirect belongs to.
- `regex` (String) The regex pattern to match URLs against.
- `replacement` (String) The replacement URL pattern. Can include capture groups from the regex.

### Optional

- `permanent` (Boolean) Whether this is a permanent (301) or temporary (302) redirect. Defaults to false.

### Read-Only

- `id` (String) The unique identifier of the redirect.
