# dokploy_server (Resource)

Manages a Dokploy server. Servers are deployment targets for applications and services.

## Example Usage

```terraform
# Register a remote server for deployments

# First, create an SSH key for authentication
resource "dokploy_ssh_key" "deploy" {
  name            = "deploy-key"
  description     = "Deployment SSH key"
  private_key     = file("~/.ssh/id_rsa")
  public_key      = file("~/.ssh/id_rsa.pub")
  organization_id = var.organization_id
}

resource "dokploy_server" "worker" {
  name        = "worker-01"
  description = "Worker server for background jobs"
  ip_address  = "192.168.1.100"
  port        = 22
  username    = "deploy"
  ssh_key_id  = dokploy_ssh_key.deploy.id
}

variable "organization_id" {
  description = "Dokploy organization ID"
  type        = string
}

output "server_id" {
  value = dokploy_server.worker.id
}
```

## Schema

### Required

- `ip_address` (String) The IP address of the server.
- `name` (String) The name of the server.
- `port` (Number) The SSH port of the server.
- `ssh_key_id` (String) The ID of the SSH key to use for the server.
- `username` (String) The SSH username for the server.

### Optional

- `description` (String) The description of the server.
- `server_type` (String) The type of server: 'deploy' or 'build'.

### Read-Only

- `id` (String) The unique identifier of the server.

## Import

Servers can be imported using their ID:

```shell
terraform import dokploy_server.example bcd890-server-id
```

Or using import blocks (Terraform 1.5+):

```hcl
import {
  to = dokploy_server.example
  id = "bcd890-server-id"
}
```

### Finding Server IDs

Use the `dokploy_servers` data source to discover server IDs:

```hcl
data "dokploy_servers" "all" {}

output "server_ids" {
  value = { for s in data.dokploy_servers.all.servers : s.name => s.id }
}
```
